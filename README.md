# ATLAS UI Kit

Практическая работа № 5: технический UI Kit для интерфейса Help Desk. В стартовом проекте была готова разметка и часть токенов, но не были закончены тёмная тема, состояния компонентов и переключение настроек. Добавлены недостающие стили и логика, компактный режим и предупреждение.

## Запуск

Откройте `index.html` в браузере или запустите в папке проекта `python -m http.server 5500` и перейдите на `http://localhost:5500`. Зависимостей и сборки нет.

## Токены

Токены расположены в `css/tokens.css`. Примитивы хранят исходные значения, семантические токены задают их роль в интерфейсе, а компонентные — конкретные параметры элементов. Примеры связей:

- `--base-blue-700` → `--color-primary` → `--button-bg-primary` → фон `.button--primary`;
- `--base-white` → `--color-on-primary` → `--button-text-primary` → текст `.button--primary`;
- `--space-5` → `--button-padding-inline` → горизонтальные отступы `.button`.

Также заданы шкалы отступов и шрифтов, радиусы, тень, цвета поверхностей, текста, границ, фокуса и уведомлений. Для тёмной темы переопределяются семантические цветовые роли. В режиме auto используется `prefers-color-scheme`, а ручной выбор получает приоритет благодаря атрибуту `data-theme`.

## Компоненты и настройки

Есть три варианта кнопки с состояниями, поля и списки выбора, сообщения info, success, error и warning. Ошибочное поле связано с текстом ошибки через `aria-describedby`, фокус обозначен через `:focus-visible`. Демонстрационная кнопка меняет сообщение под ней.

Тема и плотность выбираются независимо. Значения сохраняются в `localStorage` под ключами `atlas-theme` и `atlas-density`; при недоступном хранилище переключатели продолжают работать в текущем сеансе. Компактный режим меняет шесть токенов размеров и интервалов, без копирования правил компонентов.

## Проверки

| Условие | Что должно получиться |
| --- | --- |
| Auto при тёмной системной теме | Тёмная палитра |
| Light при тёмной системной теме | Светлая палитра: ручной выбор важнее системного |
| Обновление после выбора темы и плотности | Настройки восстанавливаются |
| Ширины 320, 375, 768, 1024 и 1440 px | Нет горизонтального переполнения |
| Tab и Shift+Tab | Видна обводка фокуса |
| Ошибка email | Граница и связанный с полем текст ошибки |
| Кнопка «Создать заявку» | Меняется текст обратной связи |

Снимки страницы находятся в папке `screenshots`: светлая тема, тёмная тема, тёмная компактная и ширина 320 px.

## Два решения

**Почему плотность задана компонентными токенами?** Меняются только размеры и интервалы, которые влияют на плотность. Общие правила кнопок и полей остаются одними и теми же, поэтому их проще поддерживать.

**Почему цвета тёмной темы не записаны внутри `.button`?** Кнопка использует семантические роли через компонентные токены. При смене темы значения ролей меняются в одном месте, а правило кнопки не приходится дублировать.
